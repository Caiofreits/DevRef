01 Preparação e pré-requisitos

Esta apostila continua diretamente o projeto Café Horizonte construído na apostila HTML e CSS. Você deve saber criar uma página, selecionar elementos por classe ou identificador e usar um formulário HTML. Em vez de abandonar esse site e começar outro sem contexto, você acrescentará comportamento à estrutura que já conhece: menu móvel, filtro do cardápio, formulário validado, preferências salvas e dados carregados de forma assíncrona.

Todos os conceitos principais serão ensinados com dados e situações do Café Horizonte. Assim, variáveis representam produtos e reservas; arrays representam o cardápio; eventos partem dos controles da página; e as requisições preparam a integração com a API estudada posteriormente.

Ponto de partida herdado

Copie a versão final da pasta criada na apostila HTML e CSS e preserve a estrutura já funcional:

cafe-horizonte/
  index.html
  css/
    styles.css
  img/

Crie então js/app.js. Antes de programar, abra o site e confirme que HTML, estilos, imagens, links e formulário ainda funcionam. Esta versão estática é o seu ponto de restauração: se uma funcionalidade JavaScript quebrar a página, você deve conseguir comparar o antes e o depois.

O que já existeO que JavaScript acrescentará
Cabeçalho e navegaçãoAbrir e fechar o menu em telas pequenas.
Cartões do cardápioFiltrar itens por categoria e atualizar a contagem.
Formulário de contato ou reservaValidar, apresentar mensagens e preparar os dados.
Layout responsivoPreservar usabilidade com e sem JavaScript.
Conteúdo estáticoCarregar sugestões e representar carregamento, vazio e erro.

Como praticar

Use exemplos pequenos. Antes de executar um trecho, tente prever o resultado. Depois altere uma parte de cada vez. Quando ocorrer um erro, leia a primeira mensagem relevante do console e localize o arquivo e a linha indicados.

Conectando o primeiro arquivo

Crie js/app.js e adicione antes de fechar body:

<script src="js/app.js"></script>

Outra opção é carregar no head com defer:

<script src="js/app.js" defer></script>

defer permite que o navegador continue lendo o HTML e execute o script depois que a estrutura do documento estiver disponível.

console.log("JavaScript carregado");

Abra o console das ferramentas do navegador. Se a mensagem não aparecer, confirme o caminho do arquivo e procure erros na guia Network.

02 Valores, variáveis e operadores

Um programa recebe valores, transforma esses valores e produz resultados. JavaScript possui números, textos, booleanos e valores especiais como null e undefined.

const itemName = "Cappuccino";
const price = 14;
const available = true;
const imageUrl = null;

console.log(typeof itemName);  // string
console.log(typeof price);     // number
console.log(typeof available); // boolean

Const e let

Use const quando a variável não receberá outra atribuição. Use let quando o valor precisará ser substituído.

const tableCapacity = 12;
let occupiedTables = 7;
occupiedTables = occupiedTables + 1;

console.log(occupiedTables);

const não torna um objeto imutável. Ele impede que a variável passe a apontar para outro valor.

const menuItem = { name: "Café coado", available: true };
menuItem.available = false; // permitido

Conversão e comparação

Dados de campos HTML chegam como texto. Converta antes de fazer cálculos.

const inputValue = "20";
const quantity = Number(inputValue);

console.log(quantity + 5);   // 25
console.log(inputValue + 5); // "205"

Prefira === e !==, que comparam valor e tipo sem conversão implícita.

console.log(5 === "5"); // false
console.log(5 == "5");  // true por conversão implícita

Template strings

const customerName = "Ana";
const availableTables = tableCapacity - occupiedTables;
const message = `Olá, ${customerName}. Temos ${availableTables} mesas disponíveis.`;

console.log(message);

Exercício calculadora do pedido

Crie variáveis para preço e quantidade de cappuccinos. Calcule o subtotal, um desconto de 10 por cento e o total final. Depois receba a quantidade como string e compare o resultado antes e depois de usar Number.

Critério de conclusão: você consegue explicar o tipo de cada variável e prever quando + soma ou concatena.

03 Decisões e repetições

Condições permitem escolher um caminho. Laços repetem uma operação enquanto uma condição for atendida ou para cada item de uma coleção.

If else e operadores lógicos

const requestedPeople = 4;
const maximumPeople = 6;

if (requestedPeople <= maximumPeople) {
  console.log("A reserva pode ser solicitada");
} else {
  console.log("Entre em contato para grupos maiores");
}

Use && quando todas as condições precisam ser verdadeiras e || quando pelo menos uma delas basta.

const hasCustomerName = true;
const hasValidDate = true;

if (hasCustomerName && hasValidDate) {
  console.log("Dados básicos da reserva válidos");
}

Valores truthy e falsy

Em uma condição, false, 0, string vazia, null, undefined e NaN são tratados como falsos. Outros valores são tratados como verdadeiros. Use esse comportamento quando ele expressar claramente a intenção.

const customerName = "";

if (!customerName.trim()) {
  console.log("Digite o nome da reserva");
}

For e for...of

const categories = ["bebidas", "doces", "salgados"];

for (let index = 0; index < categories.length; index += 1) {
  console.log(index, categories[index]);
}

for (const category of categories) {
  console.log(category);
}

Use for...of quando precisa do valor. Use o índice quando a posição também faz parte do problema.

Evitando laços infinitos

Um while precisa de uma condição que possa se tornar falsa.

let attempts = 0;

while (attempts < 3) {
  console.log(`Tentativa ${attempts + 1}`);
  attempts += 1;
}

04 Funções e organização da lógica

Uma função reúne uma responsabilidade, recebe dados por parâmetros e pode devolver um resultado.

function calculateSubtotal(price, quantity) {
  return price * quantity;
}

const subtotal = calculateSubtotal(14, 2);
console.log(subtotal); // 28

return encerra a função e entrega um valor ao ponto que a chamou. Uma função sem return explícito devolve undefined.

Funções pequenas e previsíveis

function normalizeName(name) {
  return name.trim();
}

function isValidItemName(name) {
  return normalizeName(name).length >= 3;
}

function createMenuItem(name, category, price) {
  const normalizedName = normalizeName(name);

  if (!isValidItemName(normalizedName) || price < 0) {
    return null;
  }

  return {
    id: crypto.randomUUID(),
    name: normalizedName,
    category,
    price,
    available: true,
  };
}

Cada função responde a uma pergunta. Isso facilita testar e localizar erros.

Escopo

Variáveis declaradas dentro de uma função ou bloco não devem ser usadas como se fossem globais.

function greet() {
  const message = "Olá";
  console.log(message);
}

greet();
// console.log(message); // ReferenceError

Arrow functions

const double = (value) => value * 2;
const numbers = [1, 2, 3];
const doubled = numbers.map((number) => double(number));

Arrow functions são úteis para funções curtas e callbacks. Elas também possuem regras próprias para this; por isso não substituem todas as funções tradicionais automaticamente.

Exercício

Crie uma função calculateOrderTotal(price, quantity) e outra formatCurrency(value). Teste quantidade zero, preço decimal e valores inválidos. Depois use as funções para apresentar o total de um pedido do Café Horizonte.

05 Arrays e objetos

Arrays representam coleções ordenadas. Objetos agrupam propriedades relacionadas.

const menuItems = [
  { id: "espresso", name: "Espresso", category: "bebidas", price: 8, available: true },
  { id: "brownie", name: "Brownie", category: "doces", price: 12, available: false },
];

Operações sem alterar o array original

const availableItems = menuItems.filter((item) => item.available);
const names = menuItems.map((item) => item.name);
const totalPrice = menuItems.reduce(
  (total, item) => total + item.price,
  0,
);
MétodoResultado
mapNovo array com um resultado para cada item.
filterNovo array apenas com itens aprovados pela condição.
findPrimeiro item que atende à condição ou undefined.
someBooleano indicando se algum item atende à condição.
everyBooleano indicando se todos atendem à condição.
reduceUm valor acumulado produzido a partir da coleção.

Adicionando, atualizando e removendo

const newItem = { id: "cookie", name: "Cookie", category: "doces", price: 9, available: true };
const withNewItem = [...menuItems, newItem];

const updatedItems = withNewItem.map((item) =>
  item.id === "brownie" ? { ...item, available: true } : item,
);

const remainingItems = updatedItems.filter((item) => item.id !== "espresso");

Esses padrões criam novos arrays e objetos. Eles serão importantes em React, onde atualizações imutáveis permitem detectar mudanças com previsibilidade.

Desestruturação

const { name, price } = newItem;
const [firstItem, secondItem] = menuItems;

Desestruturação retira propriedades ou posições para variáveis. Use nomes claros e evite encadear recursos apenas para reduzir linhas.

06 Depuração antes da interface

Depurar é observar o estado do programa e reduzir o problema até encontrar a suposição incorreta.

Leitura de erros

ErroSignificado comum
SyntaxErrorO código não segue a sintaxe esperada.
ReferenceErrorUm nome não existe naquele escopo.
TypeErrorUma operação foi aplicada a um valor incompatível.
RangeErrorUm valor ultrapassou um intervalo permitido.

Processo de investigação

1
Reproduza o problema com os mesmos dados.
2
Leia a mensagem e abra a primeira linha do seu próprio arquivo.
3
Inspecione os valores imediatamente antes da falha.
4
Reduza o trecho até restar o comportamento inesperado.
5
Corrija a causa e repita o cenário original.
console.log({ menuItems, totalPrice });
console.table(menuItems);

Use pontos de interrupção na guia Sources para pausar a execução e acompanhar variáveis sem espalhar muitos logs.

07 DOM e criação da interface

O DOM é a representação em objetos da estrutura HTML. JavaScript pode selecionar elementos, alterar conteúdo e criar novos elementos.

HTML do filtro de cardápio

<main class="container">
  <h1>Cardápio do Café Horizonte</h1>
  <div id="menu-filters" aria-label="Filtrar cardápio">
    <button type="button" data-category="all">Todos</button>
    <button type="button" data-category="bebidas">Bebidas</button>
    <button type="button" data-category="doces">Doces</button>
  </div>
  <p id="menu-status" aria-live="polite"></p>
  <div id="menu-list"></div>
</main>

Selecionando elementos

const filters = document.querySelector("#menu-filters");
const menuList = document.querySelector("#menu-list");
const menuStatus = document.querySelector("#menu-status");

querySelector devolve o primeiro elemento correspondente ou null. Em páginas maiores, valide seletores importantes ou mantenha o script restrito à página onde eles existem.

Renderização segura

Prefira criar elementos e preencher textContent quando o texto pode vir do usuário.

function createMenuItemElement(menuItem) {
  const card = document.createElement("article");
  card.className = "menu-card";
  card.dataset.itemId = menuItem.id;

  const title = document.createElement("h2");
  title.textContent = menuItem.name;

  const price = document.createElement("p");
  price.textContent = menuItem.price.toLocaleString("pt-BR", {
    style: "currency",
    currency: "BRL",
  });

  if (!menuItem.available) {
    card.classList.add("is-unavailable");
  }

  card.append(title, price);
  return card;
}

function renderMenu(items) {
  menuList.replaceChildren(...items.map(createMenuItemElement));
  menuStatus.textContent = `${items.length} itens encontrados.`;
}

innerHTML é conveniente para conteúdo controlado pelo desenvolvedor, mas inserir texto não confiável diretamente pode criar vulnerabilidades. textContent trata o valor como texto.

08 Eventos e formulários

Eventos informam que algo aconteceu. Um ouvinte registra qual função será executada.

filters.addEventListener("click", (event) => {
  const button = event.target.closest("button[data-category]");
  if (!button) return;

  const category = button.dataset.category;
  const visibleItems = category === "all"
    ? menuItems
    : menuItems.filter((item) => item.category === category);

  renderMenu(visibleItems);
});

preventDefault impede o envio tradicional do formulário. A lógica valida, atualiza os dados, renderiza, limpa o campo e devolve o foco.

Delegação de eventos

O exemplo anterior já usa delegação: em vez de registrar um ouvinte em cada botão, registra um no contêiner e descobre qual categoria foi solicitada.

const favoriteIds = new Set();

function toggleFavorite(itemId) {
  if (favoriteIds.has(itemId)) {
    favoriteIds.delete(itemId);
  } else {
    favoriteIds.add(itemId);
  }
}

menuList.addEventListener("click", (event) => {
  const button = event.target.closest("button[data-favorite-id]");
  if (!button) return;

  const itemId = button.dataset.favoriteId;
  toggleFavorite(itemId);
});

O valor de dataset é texto. Mantenha os identificadores do cardápio como strings para evitar conversões desnecessárias.

Separando dados e interface

Não use o texto exibido como fonte principal dos dados. Mantenha um array com itens do cardápio e gere a interface a partir dele. Essa separação reduz inconsistências e prepara o caminho para React.

09 Armazenamento local

localStorage guarda pares de texto no navegador. Objetos e arrays precisam ser convertidos para JSON.

const STORAGE_KEY = "cafe-horizonte:preferences:v1";
const defaultPreferences = { category: "all", theme: "light" };

function savePreferences(preferences) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(preferences));
}

function loadPreferences() {
  const saved = localStorage.getItem(STORAGE_KEY);
  if (!saved) return { ...defaultPreferences };

  try {
    const parsed = JSON.parse(saved);
    return typeof parsed === "object" && parsed !== null
      ? { ...defaultPreferences, ...parsed }
      : { ...defaultPreferences };
  } catch (error) {
    console.error("Preferências locais inválidas", error);
    return { ...defaultPreferences };
  }
}

const preferences = loadPreferences();
renderMenu(menuItems);

Chame savePreferences(preferences) depois de alterar tema ou filtro. O armazenamento local não é banco de dados, não sincroniza automaticamente entre dispositivos e não deve guardar reservas, senhas ou outros dados sensíveis.

10 Assincronismo, requisições e erros

Operações de rede levam tempo. Uma Promise representa um resultado futuro. async e await tornam a sequência mais legível, mas não eliminam a necessidade de tratar erros.

Carregando dados com fetch

async function loadMenu() {
  const response = await fetch("data/menu-items.json");

  if (!response.ok) {
    throw new Error(`Falha HTTP ${response.status}`);
  }

  const data = await response.json();

  if (!Array.isArray(data)) {
    throw new Error("Formato de cardápio inválido");
  }

  return data;
}

fetch não rejeita automaticamente a Promise para respostas HTTP como 404 ou 500. Por isso, verifique response.ok.

async function showMenu() {
  menuStatus.textContent = "Carregando cardápio...";

  try {
    const items = await loadMenu();
    renderMenu(items);
  } catch (error) {
    console.error(error);
    menuStatus.textContent = "Não foi possível carregar o cardápio.";
  }
}

Estados de uma operação

Uma interface que depende de rede precisa representar pelo menos carregamento, sucesso, vazio e erro. Não deixe o usuário sem saber se o clique funcionou.

Axios

O curso também apresenta Axios. A biblioteca oferece uma API conveniente, interceptadores e transformação automática de JSON. Antes de adotá-la, saiba realizar a operação com fetch e entenda o custo de adicionar uma dependência.

const response = await axios.get("/api/menu-items");
const items = response.data;

11 Módulos e JavaScript moderno

Módulos permitem separar responsabilidades sem criar muitas variáveis globais.

<script type="module" src="js/app.js"></script>
// js/storage.js
const STORAGE_KEY = "cafe-horizonte:preferences:v1";

export function savePreferences(preferences) {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(preferences));
}
// js/app.js
import { savePreferences } from "./storage.js";

O navegador exige um servidor local para vários cenários com módulos. Use Live Server ou outro servidor de desenvolvimento.

Classes e orientação a objetos

Classes podem modelar entidades com estado e comportamento, mas não são obrigatórias para todo problema.

class MenuItem {
  constructor({ id, name, category, price }) {
    this.id = id;
    this.name = name.trim();
    this.category = category;
    this.price = price;
    this.available = true;
  }

  setAvailability(available) {
    this.available = Boolean(available);
  }
}

Para dados simples que serão convertidos em JSON, objetos literais e funções costumam ser suficientes. Use classes quando o modelo e o comportamento agrupado melhorarem a clareza.

14 Exercícios de consolidação

Validador de formulário

Crie uma função que receba nome e e-mail e devolva um objeto com valid e errors. Não altere o DOM dentro dessa função. Depois use o resultado para mostrar mensagens na página.

Filtro de produtos

Dado um array de produtos com nome, preço e categoria, produza um novo array contendo apenas uma categoria e preço máximo. Exiba o resultado em uma lista.

Consumo de API

Consuma uma API pública, exiba carregamento, resultado vazio, sucesso e erro. Adicione um botão para tentar novamente.

Respostas orientadoras

Separação
Separe cálculo e validação da renderização.
Transformação
Use filter para reduzir a coleção e map para transformar dados em elementos.
Robustez
Verifique response.ok, use try...catch e mantenha a mensagem de erro visível.
