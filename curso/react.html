01 Pré-requisitos e objetivo

React organiza interfaces em componentes. Esta apostila pressupõe que você saiba escrever funções, usar arrays e objetos, tratar eventos, consumir uma API e compreender módulos JavaScript. Se esses pontos ainda exigem cópia constante, revise a apostila JavaScript antes de continuar.

O projeto progressivo continuará sendo o Café Horizonte. Agora você reconstruirá, de forma consciente, a interface feita com DOM direto. A meta não é apenas obter a mesma tela: é entender como dados, componentes, props e estado substituem as atualizações manuais do HTML.

O que será reaproveitado

Da versão HTML, CSS e JavaScriptNa versão React
Conteúdo semântico e identidade visualEstrutura JSX e estilos globais.
Array de itens do cardápioDados usados para renderizar componentes.
Filtros e formulárioEstado, eventos e validação controlada.
Funções puras de validaçãoUtilitários reaproveitados com poucos ajustes.
Manipulação manual do DOMRenderização declarativa baseada no estado.

Não copie document.querySelector, createElement ou ouvintes globais para dentro dos componentes. Compare o comportamento antigo com o novo e migre uma funcionalidade de cada vez.

Modelo mental

Em JavaScript direto, você costuma localizar um elemento e mandar alterá-lo. Em React, você descreve qual interface corresponde aos dados atuais. Quando props ou estado mudam, React executa os componentes novamente e atualiza o DOM necessário.

function Greeting({ name }) {
  return <h1>Olá, {name}</h1>;
}

Um componente é uma função que retorna JSX. JSX se parece com HTML, mas é sintaxe JavaScript transformada pela ferramenta de build.

02 Criando o projeto com Vite

Instale uma versão do Node.js compatível com a versão atual do Vite. Como esses requisitos mudam, confira o guia oficial antes de iniciar um projeto novo.

npm create vite@latest cafe-horizonte-react -- --template react
cd cafe-horizonte-react
npm install
npm run dev

O terminal informa o endereço local. Não feche o processo enquanto estiver desenvolvendo.

03 JSX e componentes

JSX permite combinar marcação e expressões JavaScript. Use chaves para inserir uma expressão.

function MenuItemCard() {
  const item = {
    name: "Café coado",
    category: "Bebidas",
  };

  return (
    <article className="menu-item-card">
      <h2>{item.name}</h2>
      <p>{item.category}</p>
    </article>
  );
}

Use className em vez de class. Um componente deve começar com letra maiúscula. O retorno precisa ter uma raiz única, que pode ser um elemento ou fragmento.

Separando componentes

src/
  components/
    Header.jsx
    MenuItemCard.jsx
    MenuList.jsx
  pages/
    HomePage.jsx
  App.jsx

Separe um componente quando ele tem responsabilidade clara, repete-se ou deixa o componente atual difícil de entender. Não transforme cada linha em um componente.

Props

Props são entradas do componente.

function MenuItemCard({ name, category, featured = false }) {
  return (
    <article className={featured ? "menu-item-card featured" : "menu-item-card"}>
      <h2>{name}</h2>
      <p>{category}</p>
    </article>
  );
}
<MenuItemCard
  name="Café coado"
  category="Bebidas"
  featured
/>

Props são somente leitura. O componente filho não deve modificar o objeto recebido para tentar atualizar o pai.

Children e composição

function Panel({ title, children }) {
  return (
    <section className="panel">
      <h2>{title}</h2>
      {children}
    </section>
  );
}

Composição permite que o pai forneça conteúdo sem criar muitas propriedades específicas.

04 Listas, condições e chaves

Use map para transformar dados em elementos.

const menuItems = [
  { id: "cafe-coado", name: "Café coado", category: "bebidas" },
  { id: "bolo-cenoura", name: "Bolo de cenoura", category: "doces" },
];

function MenuList({ items }) {
  if (items.length === 0) {
    return <p>Nenhum item disponível no cardápio.</p>;
  }

  return (
    <div className="menu-list">
      {items.map((item) => (
        <MenuItemCard key={item.id} {...item} />
      ))}
    </div>
  );
}

key identifica o item entre renderizações. Prefira um identificador estável dos dados. Usar o índice pode causar associações incorretas quando itens são inseridos, removidos ou reordenados.

Renderização condicional

{isLoading && <p>Carregando...</p>}
{error && <p role="alert">{error}</p>}
{menuItems.length > 0 ? <MenuList items={menuItems} /> : <EmptyMenu />}

Escolha a forma que deixa os estados possíveis fáceis de ler. Se muitas condições se cruzam, calcule variáveis ou retorne cedo.

05 Estado e eventos

Estado é a memória de um componente. useState devolve o valor atual e uma função para solicitar a próxima renderização.

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  function handleIncrement() {
    setCount((current) => current + 1);
  }

  return (
    <button type="button" onClick={handleIncrement}>
      Itens favoritos {count}
    </button>
  );
}

Não altere a variável diretamente. A função de atualização informa ao React que existe um novo estado.

Estado como instantâneo

Cada renderização trabalha com os valores daquele momento. Quando o próximo valor depende do anterior, use a função atualizadora.

setCount((current) => current + 1);

Atualizando arrays e objetos

const [menuItems, setMenuItems] = useState(initialMenuItems);

function addMenuItem(item) {
  setMenuItems((current) => [...current, item]);
}

function toggleAvailable(itemId) {
  setMenuItems((current) =>
    current.map((item) =>
      item.id === itemId
        ? { ...item, available: !item.available }
        : item,
    ),
  );
}

Não use push no array do estado nem altere uma propriedade do objeto existente. Crie os próximos valores.

Onde o estado deve viver

Mantenha o estado no componente comum mais próximo que precisa compartilhar os dados. Esse movimento é chamado de elevar o estado. Não torne global um estado que pertence a uma única seção.

06 Formulários controlados

Em um campo controlado, o valor exibido vem do estado e o evento atualiza esse estado.

import { useState } from "react";

function ReservationForm({ onCreateReservation }) {
  const [form, setForm] = useState({ name: "", people: 2 });
  const [error, setError] = useState("");

  function handleChange(event) {
    const { name, value } = event.target;
    setForm((current) => ({ ...current, [name]: value }));
  }

  function handleSubmit(event) {
    event.preventDefault();

    if (form.name.trim().length < 3 || Number(form.people) < 1) {
      setError("Informe seu nome e ao menos uma pessoa.");
      return;
    }

    onCreateReservation({
      id: crypto.randomUUID(),
      name: form.name.trim(),
      people: Number(form.people),
    });

    setForm({ name: "", people: 2 });
    setError("");
  }

  return (
    <form onSubmit={handleSubmit}>
      <label htmlFor="name">Nome da reserva</label>
      <input
        id="name"
        name="name"
        value={form.name}
        onChange={handleChange}
      />

      <label htmlFor="people">Número de pessoas</label>
      <input
        id="people"
        name="people"
        type="number"
        min="1"
        value={form.people}
        onChange={handleChange}
      />

      {error && <p role="alert">{error}</p>}

      <button type="submit">Solicitar reserva</button>
    </form>
  );
}

O atributo em JSX é htmlFor. O nome dos campos corresponde às propriedades do estado para que uma função trate ambos.

Estado derivado

Não armazene no estado um valor que pode ser calculado durante a renderização.

const visibleMenuItems = menuItems.filter((item) =>
  item.name.toLowerCase().includes(search.toLowerCase()),
);

Guardar visibleMenuItems em outro estado exigiria sincronização e poderia criar divergências.

07 Efeitos e requisições

Efeitos sincronizam um componente com sistemas externos, como rede, armazenamento, temporizadores ou APIs do navegador. Eles não são a ferramenta padrão para calcular dados derivados.

import { useEffect, useState } from "react";

function RemoteMenu() {
  const [menuItems, setMenuItems] = useState([]);
  const [status, setStatus] = useState("loading");

  useEffect(() => {
    const controller = new AbortController();

    async function loadMenu() {
      try {
        setStatus("loading");
        const response = await fetch(`${import.meta.env.VITE_API_URL}/api/menu-items`, {
          signal: controller.signal,
        });

        if (!response.ok) {
          throw new Error(`Falha HTTP ${response.status}`);
        }

        const body = await response.json();

        if (!Array.isArray(body.data)) {
          throw new Error("Formato de cardápio inválido");
        }

        setMenuItems(body.data);
        setStatus("success");
      } catch (error) {
        if (error.name !== "AbortError") {
          console.error(error);
          setStatus("error");
        }
      }
    }

    loadMenu();
    return () => controller.abort();
  }, []);

  if (status === "loading") return <p>Carregando...</p>;
  if (status === "error") return <p role="alert">Falha ao carregar.</p>;

  return <MenuList items={menuItems} />;
}

O retorno do efeito é a limpeza. O AbortController cancela a requisição quando o componente deixa de existir. Em aplicações maiores, roteadores e bibliotecas de dados podem oferecer estratégias melhores para carregamento, cache e revalidação.

Dependências do efeito

Todo valor reativo usado pelo efeito deve ser considerado na lista de dependências. Não remova uma dependência apenas para silenciar a ferramenta. Reestruture a lógica ou estabilize a entrada quando necessário.

Quando não usar efeito

Transformar props
Para transformar props antes de exibir.
Calcular lista filtrada
Para calcular uma lista filtrada.
Responder a um clique
Para responder diretamente a um clique.
Reiniciar estado
Para reiniciar estado quando uma chave ou estrutura de componente resolve o problema.

08 CSS no React

React não impõe uma única estratégia de estilo. Comece com CSS comum e classes claras.

import "./MenuItemCard.css";

export function MenuItemCard({ name, category, available }) {
  const className = available
    ? "menu-item-card"
    : "menu-item-card menu-item-card--unavailable";

  return (
    <article className={className}>
      <h2>{name}</h2>
      <p>{category}</p>
    </article>
  );
}

Escolha de abordagem

AbordagemVantagemCuidado
CSS globalSimples para base, tokens e tipografia.Classes podem afetar regiões inesperadas.
CSS por componenteMantém arquivos próximos do componente.O arquivo continua global sem uma técnica de escopo.
CSS ModulesCria nomes locais de classe.Exige importar e usar o objeto de estilos.
InlineÚtil para valor calculado pontual.Não atende bem pseudoestados e regras complexas.

Evite misturar várias estratégias sem motivo. A equipe deve conseguir prever onde localizar uma regra.

09 Rotas e páginas

Instale a versão de React Router escolhida para o projeto e confira a documentação correspondente. O exemplo abaixo mostra a ideia central de uma configuração declarativa.

npm install react-router-dom
import { BrowserRouter, Link, Route, Routes } from "react-router-dom";
import { HomePage } from "./pages/HomePage";
import { MenuItemPage } from "./pages/MenuItemPage";
import { ReservationPage } from "./pages/ReservationPage";
import { NotFoundPage } from "./pages/NotFoundPage";

export default function App() {
  return (
    <BrowserRouter>
      <header>
        <Link to="/">Café Horizonte</Link>
        <Link to="/reservas">Reservas</Link>
      </header>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/cardapio/:itemId" element={<MenuItemPage />} />
        <Route path="/reservas" element={<ReservationPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Routes>
    </BrowserRouter>
  );
}

Use Link para navegação interna sem recarregar todo o documento. Parâmetros de rota identificam recursos. A aplicação ainda precisa tratar carregamento, item inexistente e falha de rede.

Publicação de uma SPA

Ao atualizar uma rota como /cardapio/cafe-coado, o servidor precisa devolver index.html para que o roteador assuma a navegação. Configure o fallback no provedor. Sem isso, rotas internas podem funcionar por clique e retornar 404 ao atualizar. É exatamente por isso que o site construído ao final deste módulo usa HashRouter — o DevRef é hospedado como arquivos estáticos, sem um servidor para configurar esse fallback.

10 Contexto, reducer e hooks personalizados

Contexto fornece um valor a descendentes sem passar a mesma prop por muitos níveis. Use-o para dados realmente compartilhados, não como substituto automático de todas as props.

import { createContext, useContext, useState } from "react";

const ThemeContext = createContext(null);

export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");
  const value = { theme, setTheme };

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme() {
  const context = useContext(ThemeContext);

  if (!context) {
    throw new Error("useTheme deve ser usado dentro de ThemeProvider");
  }

  return context;
}

Reducer para transições relacionadas

function menuReducer(state, action) {
  switch (action.type) {
    case "added":
      return [...state, action.item];
    case "availabilityToggled":
      return state.map((item) =>
        item.id === action.itemId
          ? { ...item, available: !item.available }
          : item,
      );
    case "removed":
      return state.filter((item) => item.id !== action.itemId);
    default:
      throw new Error(`Ação desconhecida ${action.type}`);
  }
}

Um reducer concentra transições de estado e torna explícito o que pode acontecer. Ele não é necessário para um único booleano.

Hook personalizado

import { useEffect, useState } from "react";

export function useDocumentTitle(title) {
  useEffect(() => {
    const previous = document.title;
    document.title = title;

    return () => {
      document.title = previous;
    };
  }, [title]);
}

Um hook personalizado reutiliza lógica que usa hooks. O nome começa com use e as regras de hooks continuam válidas.
