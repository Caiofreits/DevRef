01 Antes de escrever o primeiro código

Esta apostila foi escrita para quem nunca programou. Ao terminar, você deverá conseguir criar uma página institucional simples, adaptá-la para celular e computador e publicá-la. O projeto usado durante os capítulos é o site fictício Café Horizonte. Cada parte nova será aplicada ao mesmo site para que você veja como as decisões se conectam.

O que você precisa saber antes de começar

Você precisa saber criar, renomear e localizar pastas no computador. Não é necessário conhecer programação. Separe períodos de 40 a 60 minutos e digite os exemplos. Copiar e colar pode ajudar a conferir um erro, mas não substitui a prática de escrever.

Ferramentas necessárias

Navegador
Um navegador atualizado, como Chrome, Edge ou Firefox.
Editor
O Visual Studio Code ou outro editor de código.
Organização
Uma pasta exclusiva para cada projeto.
Live Server
A extensão Live Server é opcional, mas facilita a atualização da página.

Método de estudo

1
Leia o objetivo do capítulo.
2
Digite o exemplo e abra o resultado no navegador.
3
Modifique um valor e observe o que muda.
4
Faça o exercício sem consultar a resposta.
5
Avance somente quando o critério de conclusão estiver atendido.

Se o resultado não aparecer como esperado, não recomece imediatamente. Verifique o nome dos arquivos, salve as alterações e use as ferramentas do navegador para localizar o problema.

02 Como um site chega ao navegador

Um site básico é um conjunto de arquivos. O HTML descreve o conteúdo. O CSS define a apresentação. Imagens, fontes e outros recursos completam a página. Quando você abre index.html, o navegador lê o documento, encontra referências para outros arquivos e monta o resultado visual.

Estrutura inicial do projeto

Crie uma pasta chamada cafe-horizonte. Dentro dela, crie a seguinte estrutura:

cafe-horizonte/
  index.html
  css/
    styles.css
  img/

O nome index.html é usado com frequência porque servidores procuram esse arquivo como página inicial. A pasta css separa os estilos, e a pasta img guarda as imagens.

Primeiro teste no navegador

Digite no arquivo index.html:

Minha primeira página

Salve o arquivo e abra-o no navegador. O texto aparece porque o navegador consegue exibir conteúdo mesmo sem uma estrutura completa. Isso é útil para um teste, mas uma página correta precisa declarar seu tipo, idioma, configurações e conteúdo.

Verificação rápida

Local
Você sabe em qual pasta o projeto está salvo.
Nome do arquivo
O arquivo se chama index.html, sem uma extensão adicional como .txt.
Ciclo de teste
Alterar o texto, salvar e atualizar o navegador muda o resultado.

03 HTML passo a passo

HTML significa linguagem de marcação de hipertexto. Ele marca cada parte do conteúdo com elementos. Um elemento costuma ter uma tag de abertura, conteúdo e tag de fechamento.

<p>O café abre às 8 horas.</p>

<p> inicia um parágrafo e </p> encerra o parágrafo. O navegador usa essa informação para entender a função do texto.

Documento completo

Substitua o conteúdo de index.html por:

<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Café Horizonte</title>
  </head>
  <body>
    <h1>Café Horizonte</h1>
    <p>Cafés especiais e comida feita com calma.</p>
  </body>
</html>

Entendendo cada parte

TrechoFunção
<!doctype html>Informa que o documento usa HTML moderno.
<html lang="pt-BR">Envolve a página e informa o idioma principal.
<head>Guarda configurações e informações que não formam o conteúdo principal.
<meta charset="UTF-8">Permite representar corretamente acentos e outros caracteres.
meta viewportFaz a largura da página acompanhar a largura do dispositivo.
<title>Define o texto mostrado na aba do navegador.
<body>Contém o que será exibido na página.
<h1>Representa o título principal.
<p>Representa um parágrafo.

O recuo não muda o funcionamento do HTML, mas revela quais elementos estão dentro de outros. Essa relação é chamada de aninhamento.

Títulos e parágrafos

HTML oferece títulos de h1 a h6. Os números representam níveis na estrutura, não tamanhos escolhidos para o visual. Use CSS para mudar a aparência.

<h1>Café Horizonte</h1>
<h2>Nosso cardápio</h2>
<h3>Cafés quentes</h3>
<p>Escolha entre espresso, coado e cappuccino.</p>

Uma página normalmente tem um título principal claro. Os subtítulos organizam seções e subseções em ordem coerente.

Links

O elemento a cria um link. O atributo href indica o destino.

<a href="https://www.instagram.com/">Conheça nosso Instagram</a>
<a href="cardapio.html">Abrir o cardápio</a>

O primeiro endereço é absoluto e aponta para outro site. O segundo é relativo e procura um arquivo dentro do projeto. Se o arquivo não existir ou o nome estiver diferente, o link falhará.

Imagens

Coloque uma imagem chamada fachada.jpg na pasta img e adicione:

<img
  src="img/fachada.jpg"
  alt="Fachada do Café Horizonte com mesas na calçada"
/>

src informa o caminho. alt descreve a informação transmitida pela imagem. Ele ajuda pessoas que usam leitores de tela e aparece quando a imagem não carrega. Uma imagem meramente decorativa pode usar alt="".

Listas

Use uma lista quando vários itens pertencem ao mesmo conjunto.

<h2>Destaques</h2>
<ul>
  <li>Café de pequenos produtores</li>
  <li>Opções sem lactose</li>
  <li>Ambiente com Wi-Fi</li>
</ul>

ul cria uma lista sem ordem. ol cria uma lista ordenada. Cada item usa li.

Anatomia de uma tag e seus atributos

Antes de continuar o projeto, observe como uma instrução HTML é formada:

<a class="button" href="#cardapio">Ver cardápio</a>
<a
Inicia a tag de abertura.
class="button"
Atribui uma classe que poderá ser selecionada pelo CSS.
href="#cardapio"
Informa o destino do link.
Ver cardápio
É o conteúdo visível.
</a>
Fecha o elemento.

Alguns elementos não envolvem conteúdo e, por isso, não possuem tag de fechamento, como img, input, meta e link. Aspas nos valores de atributos evitam ambiguidades e devem ser mantidas como padrão do projeto.

04 Estrutura semântica da página

Elementos semânticos dizem qual é o papel de cada região. Eles ajudam quem lê o código, mecanismos de busca e tecnologias assistivas.

<body>
  <header>
    <a href="index.html">Café Horizonte</a>
    <nav aria-label="Navegação principal">
      <a href="#sobre">Sobre</a>
      <a href="#cardapio">Cardápio</a>
      <a href="#contato">Contato</a>
    </nav>
  </header>
  <main>
    <section id="sobre">
      <h1>Café Horizonte</h1>
      <p>Cafés especiais e comida feita com calma.</p>
    </section>
    <section id="cardapio">
      <h2>Cardápio</h2>
      <article>
        <h3>Cappuccino</h3>
        <p>Espresso, leite vaporizado e espuma.</p>
      </article>
    </section>
  </main>
  <footer id="contato">
    <p>Rua Exemplo, 100</p>
  </footer>
</body>

Escolhendo o elemento correto

ElementoUse quando
headerA região apresenta uma página ou seção.
navO conjunto contém links de navegação importantes.
mainA região contém o assunto principal da página.
sectionO conteúdo forma uma seção temática, normalmente com título.
articleO conteúdo faz sentido como unidade independente.
asideO conteúdo é complementar ao assunto principal.
footerA região encerra uma página ou seção.
divÉ necessário apenas um agrupamento sem significado específico.

Semântica não é escolher uma tag diferente para cada bloco. É representar a estrutura real. Uma div continua correta quando nenhum elemento semântico descreve o agrupamento.

Acessibilidade desde o início

Links descritivos
Escreva textos de link que indiquem o destino. Evite vários links chamados apenas de "clique aqui".
Cor não é suficiente
Não use cor como única forma de transmitir informação.
Ordem lógica
Mantenha uma ordem lógica de títulos.
Elementos nativos
Use elementos interativos nativos, como button para ações e a para navegação.
Foco visível
Não remova o contorno de foco sem fornecer uma alternativa visível.

05 CSS desde o primeiro estilo

CSS é uma linguagem de regras. Cada regra seleciona elementos e declara propriedades.

p {
  color: #333333;
  font-size: 1rem;
}

p é o seletor. color e font-size são propriedades. Os valores vêm depois dos dois-pontos, e cada declaração termina com ponto e vírgula.

Ligando o CSS ao HTML

Dentro de head, acrescente:

<link rel="stylesheet" href="css/styles.css" />

Agora escreva em css/styles.css:

body {
  background-color: #f6f1e8;
  color: #2f241f;
  font-family: Arial, sans-serif;
}

Se nada mudar, confira se o arquivo foi salvo e se o caminho começa em css/. No navegador, abra as ferramentas de desenvolvimento e verifique se existe um erro 404 ao carregar styles.css.

Classes e identificadores

Uma classe pode ser reutilizada. Um identificador deve representar um elemento específico na página.

<a class="button" href="#cardapio">Ver cardápio</a>
.button {
  background-color: #6b3f2a;
  color: #ffffff;
  padding: 0.75rem 1rem;
  text-decoration: none;
}

No CSS, o ponto seleciona uma classe. O caractere # seleciona um id. Prefira classes para estilos e use id principalmente para destinos internos, formulários e integrações específicas.

Cascata e conflito

Quando duas regras afetam a mesma propriedade, o navegador considera origem, importância, especificidade e ordem. Para começar, use seletores simples e evite !important.

.button {
  color: white;
}

.button-secondary {
  color: #6b3f2a;
}

Um elemento com as duas classes recebe a cor da segunda regra porque os seletores têm força semelhante e ela aparece depois.

06 Espaçamento e modelo de caixa

Todo elemento forma uma caixa composta por conteúdo, preenchimento, borda e margem.

ParteSignificado
conteúdoTexto, imagem ou área interna do elemento.
paddingEspaço entre o conteúdo e a borda.
borderContorno da caixa.
marginEspaço externo entre a caixa e seus vizinhos.

Comece o CSS com uma base previsível:

* {
  box-sizing: border-box;
}

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
}

img {
  display: block;
  max-width: 100%;
}

Com border-box, a largura declarada inclui preenchimento e borda. max-width: 100% impede uma imagem de ultrapassar o espaço disponível.

Conteúdo centralizado

.container {
  width: min(100% - 2rem, 70rem);
  margin-inline: auto;
}

A expressão escolhe o menor valor entre a largura disponível com margens e o limite de 70rem. Isso mantém o conteúdo confortável em telas pequenas e evita linhas excessivamente longas em telas grandes.

Inspecionando uma caixa

1
Abra as ferramentas do navegador.
2
Use o seletor de elementos e clique em um cartão.
3
Abra a área Computed ou Layout.
4
Observe os valores de conteúdo, padding, border e margin.
5
Altere um valor temporariamente e veja o resultado.

07 Layout com Flexbox

Flexbox organiza itens em uma dimensão principal. A propriedade é aplicada ao elemento pai, chamado contêiner flexível.

<section class="menu container" id="cardapio">
  <article class="menu-card">
    <h2>Espresso</h2>
    <p>Intenso e equilibrado.</p>
  </article>
  <article class="menu-card">
    <h2>Cappuccino</h2>
    <p>Cremoso e suave.</p>
  </article>
</section>
.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

.menu-card {
  flex: 1 1 16rem;
  padding: 1rem;
  border: 1px solid #d8c9bb;
  border-radius: 0.75rem;
  background-color: #ffffff;
}

gap cria espaço entre os itens. flex-wrap permite a quebra de linha. Em flex: 1 1 16rem, o cartão pode crescer, pode encolher e começa com uma base de 16rem.

Alinhamento

justify-content trabalha no eixo principal. align-items trabalha no eixo transversal. O eixo principal muda com flex-direction.

.site-header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}

Não memorize cada valor de uma vez. Abra o DevTools, ative o editor visual de Flexbox e teste as opções.

08 Responsividade orientada ao conteúdo

Um layout responsivo se adapta ao espaço disponível. Comece com a versão estreita e acrescente mudanças apenas quando o conteúdo precisar.

.site-header {
  display: flex;
  flex-direction: column;
  align-items: flex-start;
}

@media (min-width: 48rem) {
  .site-header {
    flex-direction: row;
    align-items: center;
  }
}

O breakpoint não significa tablet por definição. Ele indica o ponto em que a composição tem espaço para mudar. Teste larguras intermediárias, aumento de fonte e textos maiores do que os exemplos.

UnidadeUso comum

remEspaçamentos e fontes relacionados à configuração raiz.
%Medidas relativas ao contêiner.
vw e vhMedidas relativas à área visível, usadas com cuidado.

Toque
Links e botões têm área confortável para toque.

Independência visual

09 Formulários compreensíveis

Um formulário coleta dados. HTML fornece controles, identificação e validação básica, mas o envio real normalmente depende de um servidor ou serviço externo.

<form class="reservation-form" action="/reservas" method="post">
  <fieldset>
    <legend>Dados da reserva</legend>
    <div class="field">
      <label for="name">Nome</label>
      <input id="name" name="name" type="text" autocomplete="name" required />
    </div>
    <div class="field">
      <label for="email">E-mail</label>
      <input id="email" name="email" type="email" autocomplete="email" required />
    </div>
    <div class="field">
      <label for="time">Horário</label>
      <input
        id="time"
        name="time"
        type="time"
        min="08:00"
        max="18:00"
        step="1800"
        aria-describedby="time-hint"
        required
      />
      <p id="time-hint" class="field-hint">
        Escolha um horário entre 8h e 18h, de terça a domingo.
      </p>
    </div>
    <div class="field">
      <label for="notes">Observações</label>
      <textarea id="notes" name="notes" rows="4"></textarea>
    </div>
  </fieldset>
  <button type="submit">Solicitar reserva</button>
</form>

form reúne os dados enviados; fieldset agrupa os controles da mesma finalidade; e legend dá um nome ao grupo. label descreve cada controle e seu for aponta para o id correspondente. input recebe textos curtos, min e max restringem um intervalo permitido — como no horário da reserva — e textarea recebe observações maiores. button envia o formulário. O atributo name identifica o dado enviado, type informa o formato esperado, autocomplete ajuda o navegador e required impede o envio vazio no navegador. A API ainda precisará validar tudo novamente.

Erros comuns em formulários

placeholder no lugar de label
Faz a identificação desaparecer durante a digitação.
id repetido
Repetir o mesmo id quebra a associação entre rótulo e campo.
name ausente
Esquecer name impede que o valor seja identificado no envio tradicional.
div clicável
Usar uma div clicável no lugar de button remove comportamentos importantes de teclado.

12 Publicação do site

Um site estático pode ser publicado em serviços que recebem os arquivos HTML, CSS e imagens. O processo exato muda conforme o provedor, mas a preparação é semelhante.

Checklist antes do envio

Arquivo inicial
O arquivo inicial se chama index.html.
Caminhos
Os caminhos usam nomes e letras maiúsculas exatamente como os arquivos.
Sem caminhos locais
Não existem caminhos locais como C:\Users\....
Sem dados sensíveis
Não existem senhas, chaves ou informações privadas nos arquivos.
Testes
Links, imagens e formulário foram testados.
Responsivo
O site funciona em celular e computador.

Domínio, DNS e HTTPS

O domínio é o nome usado para acessar o site. O DNS relaciona esse nome ao serviço que entrega os arquivos. HTTPS protege a comunicação entre navegador e servidor. Muitos provedores de sites estáticos configuram HTTPS automaticamente depois que o domínio aponta corretamente.

Diagnóstico após a publicação

SintomaVerificação
CSS não carregaAbra Network, procure 404 e confira maiúsculas e caminho relativo.
Imagem aparece localmente e falha onlineVerifique o nome exato e se a imagem foi enviada.
Mudança antiga continua visívelAtualize ignorando cache e confirme qual arquivo foi publicado.
Link interno não funcionaConfira se o href corresponde ao id existente.

13 Exercícios e respostas orientadoras

Exercício página pessoal

Crie uma página com apresentação, lista de habilidades, dois projetos e contato. Use HTML semântico e pelo menos uma imagem com texto alternativo.

Orientação de resposta: comece pelo conteúdo sem CSS. Depois use uma classe .container, estilize tipografia e transforme os projetos em cartões flexíveis.

Exercício cartões responsivos

Crie quatro cartões que ocupem uma coluna em telas estreitas e se distribuam automaticamente quando houver espaço.

Orientação de resposta: aplique display: flex, flex-wrap: wrap e gap ao pai. Nos filhos, experimente flex: 1 1 14rem.

Exercício formulário

Crie campos para nome, e-mail, assunto e mensagem. Todos devem possuir rótulo. Nome, e-mail e mensagem são obrigatórios.

Orientação de resposta: associe cada label for ao input id, escolha type="email" para o e-mail e use textarea para a mensagem.
